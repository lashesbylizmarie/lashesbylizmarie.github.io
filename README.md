## Config

### Sass

``sass assets/sass/main.scss assets/css/main.css`` | Compile Sass files into main CSS file. Run this command every time you want to refresh changes to Sass/CSS

``sass --watch assets/sass/main.scss:assets/css/main.css`` | Continuously compile Sass files into main CSS file. Run in a seperate terminal tab to refresh changes to Sass/CSS every time an scss file is saved.

### Git

1. Develop on a release branch (ie. ``release/vX.Y.Z``). 
2. Once a release is complete, merge it to the ``dev`` branch and push to remote. 3. Pushing ``dev`` to remote initiates an action in GitHub. Need to review what this does !INC
4. Once a release is ready for production, merge ``dev`` into ``main``.
